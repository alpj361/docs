**Codex** es el espacio donde tus notas dejan de estar aisladas. Puedes convertir una pista en una persona, relacionarla con una organización, ubicarla en un lugar y conservar la fuente que la respalda.

No tienes que organizarlo todo desde el primer momento. Empieza con una Nota rápida y añade estructura cuando la necesites.

## Las fichas que encontrarás

| Nombre en la app | Para qué sirve | Ejemplo |
| --- | --- | --- |
| **Persona** | Alguien real | Una abogada, un testigo, una periodista o un cliente |
| **Organización** | Una institución, empresa o grupo | Un tribunal, universidad, partido o negocio |
| **Territorio** | Un lugar, área o punto del mapa | Un país, municipio, colonia, zona o edificio |
| **Evento** | Algo que ocurrió o ocurrirá | Una audiencia, reunión, protesta, publicación o lanzamiento |
| **Historia** | La investigación, caso o tema que reúne el trabajo | Una tesis, un proceso legal o una campaña |
| **Documento o evidencia** | Un archivo que necesitas conservar | Un contrato, fotografía, encuesta, expediente o tabla |
| **Herramienta o sistema** | Un método, plataforma o infraestructura relevante | Un protocolo, programa, maquinaria o sistema informático |
| **Fuente** | El origen de una información | Una entrevista, libro, enlace, archivo o conjunto de datos |

## Elementos para capturar y explorar

| Nombre en la app | Para qué sirve |
| --- | --- |
| **Nota rápida** | Guarda una idea, cita, pista, hallazgo o pendiente |
| **Publicación** | Conserva contenido de una red, sitio o plataforma |
| **Perfil** | Representa un tipo de persona o audiencia, no un individuo real |
| **Simulación** | Explora cómo podrían reaccionar personas o perfiles ante un escenario |

<Tip>
  Una Nota rápida puede decir simplemente: “El contrato se adjudicó dos días antes del cierre”. Más adelante puedes conectarla con la persona, el evento, el documento y la fuente correspondientes.
</Tip>

## Historia y Espacio no son lo mismo

Una **Historia** representa en Codex el caso, tema o relato que quieres conservar y relacionar con Personas, Organizaciones, Territorios, Eventos, Documentos y Fuentes.

Un **Espacio** es donde desarrollas el trabajo: escribes una demanda, un artículo, una novela o una investigación y consultas el contexto que necesita. Puedes relacionar una Historia con uno o varios Espacios sin convertirlos en lo mismo.

## Persona y Perfil no son lo mismo

Una **Persona** corresponde a alguien real.

Un **Perfil** representa un grupo que quieres comprender. Por ejemplo: “Estudiantes universitarios que trabajan por la tarde”. Puede incluir necesidades, hábitos y preocupaciones, pero debe estar claramente identificado como una representación.
