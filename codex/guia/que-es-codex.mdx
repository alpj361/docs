**Codex** es el espacio de conocimiento de Pulse Journal. Sirve para reunir lo que sabes, de dónde salió y cómo se relaciona.

Puedes usarlo para una investigación, un caso legal, una tesis, un análisis de mercado o cualquier trabajo donde necesites conectar personas, organizaciones, lugares, fechas, documentos y fuentes.

## Los nombres que verás en la app

Pulse Journal conserva nombres cortos para que todos los equipos compartan el mismo lenguaje. Esta guía añade su significado cotidiano en español.

| Nombre en la app | Qué significa | Ejemplo |
| --- | --- | --- |
| **Actor** | Persona real | Una diputada, un testigo, una periodista o un cliente |
| **Entidad** | Organización o grupo | Una empresa, un tribunal, una universidad o un partido |
| **Territorio** | Lugar, área o punto del mapa | Un país, municipio, colonia, zona comercial o edificio |
| **Evento** | Hecho situado en el tiempo | Una audiencia, protesta, publicación, reunión o lanzamiento |
| **Historia** | Investigación, caso o tema central | “Caso de contratación municipal” o “Campaña de regreso a clases” |
| **Objeto** | Documento, evidencia o conjunto de datos | Un expediente, fotografía, contrato, encuesta o archivo |
| **Artefacto** | Herramienta, sistema, método o infraestructura | Una plataforma, protocolo, algoritmo o maquinaria |
| **Source** | Fuente de información | Una entrevista, enlace, libro, archivo, persona consultada o dataset |

<Note>
  **Source** es el nombre visible en la app. En esta documentación lo explicamos como **Fuente**.
</Note>

## Elementos para capturar información rápidamente

También verás elementos auxiliares. Ayudan a guardar información antes de decidir dónde encaja.

| Nombre en la app | Traducción práctica | Para qué sirve |
| --- | --- | --- |
| **Post** | Publicación | Conserva una publicación de una red, sitio o plataforma |
| **Snippet** | Nota breve o fragmento | Guarda una idea, cita, hallazgo, párrafo o recordatorio |
| **Perfil** | Tipo de persona o audiencia | Representa un grupo, no a una persona real |
| **Simulación** | Exploración de escenarios | Prueba cómo podrían reaccionar actores o perfiles |

Un **Snippet (Nota breve)** puede empezar como un apunte sencillo: “El contrato se adjudicó dos días antes del cierre”. Después puedes relacionarlo con el Evento, Objeto y Source que lo respaldan.

Post y Snippet se guardan en Codex, pero no forman parte de los ocho tipos oficiales de ítem.

## Cómo pensar una investigación

Una **Historia (Investigación o caso)** puede funcionar como centro. Desde allí puedes relacionar:

- **Actor:** personas involucradas;
- **Entidad:** organizaciones;
- **Territorio:** lugares;
- **Evento:** hechos y fechas;
- **Objeto:** documentos o evidencia;
- **Source:** fuentes;
- **Snippet:** notas breves y hallazgos.

No necesitas completar todo al empezar. Puedes guardar primero una nota, enlace o documento y conectarlo cuando la investigación tenga más forma.

## Persona real y Perfil no son lo mismo

- **Actor (Persona real):** corresponde a un individuo que existe.
- **Perfil:** representa un tipo de persona o grupo que quieres comprender.

Ejemplo de Perfil: “Estudiantes universitarios que trabajan por la tarde”. El Perfil puede incluir necesidades, hábitos y preocupaciones, pero debe verse claramente como una representación, no como una persona real.
