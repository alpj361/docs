Un **campo** guarda un dato: fecha de nacimiento, cargo, tribunal, nivel de confianza o enlace.

Un **preset** es una plantilla de campos. La app usa la palabra preset porque es el nombre compartido por la interfaz y el agente, pero puedes pensarlo como un **machote reutilizable**.

## Ejemplos de presets

- **Personal:** descripción, edad, país y fecha de nacimiento.
- **Investigación periodística:** verificación, fuente principal, pendientes y nivel de confianza.
- **Legal:** número de expediente, tribunal, etapa procesal y próxima audiencia.
- **Académico:** autor, año, metodología, hallazgos y formato de cita.
- **Marketing:** audiencia, necesidad, canal, mensaje y resultado observado.

Una ficha puede combinar varios presets. Un Actor puede usar el preset Personal y también uno Legal si participa en un caso.

## Agregar campos

Cuando pulses **Más campos**:

1. Busca el concepto por su nombre cotidiano.
2. Reutiliza un campo existente si significa lo mismo.
3. Revisa las sugerencias parecidas.
4. Crea uno nuevo únicamente si no existe.
5. Escribe un nombre claro, el tipo de dato y por qué lo necesitas.

Por ejemplo, antes de crear “Profesión”, revisa si ya existe “Ocupación”. Esto evita que una misma investigación termine con dos campos que significan lo mismo.

## Crear un preset personal

Puedes crear una plantilla para tu propio trabajo, como:

- “Caso penal”;
- “Investigación de corrupción”;
- “Tesis universitaria”;
- “Análisis de campaña”.

El preset reúne campos, pero no obliga a completar datos que todavía desconoces. Tampoco borra información si cambias la plantilla más adelante.

## Cómo se presenta cada dato

| Tipo de dato | Cómo debería verse |
| --- | --- |
| Texto o párrafo | Campo para escribir |
| Fecha o período | Calendario o selector temporal |
| Sí / No | Casilla o interruptor |
| Opciones | Lista con nombres legibles |
| Etiquetas | Chips editables |
| Escala | Selector de 1 a 5 |
| Eje | Deslizador entre dos extremos visibles |
| Referencia | Tarjeta de una persona, lugar, objeto o Source |
| Varias referencias | Selector de varios elementos |
| Archivo o imagen | Vista previa |
| Coordenadas | Mini mapa |
| Lista repetible | Filas que puedes añadir |
| Fórmula | Resultado calculado de solo lectura |

La interfaz debe mostrar nombres y vistas previas. No debería pedirte que trabajes con identificadores técnicos.
