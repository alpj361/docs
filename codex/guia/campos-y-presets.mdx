Un **campo** guarda un dato, como una fecha de nacimiento, un cargo, un tribunal, un nivel de confianza o un enlace.

Una **plantilla** reúne varios campos que suelen usarse juntos. Así puedes preparar una ficha para tu trabajo sin añadir cada dato manualmente.

## Ejemplos de plantillas

- **Personal:** descripción, edad, país y fecha de nacimiento.
- **Investigación periodística:** verificación, fuente principal, pendientes y nivel de confianza.
- **Legal:** número de expediente, tribunal, etapa procesal y próxima audiencia.
- **Académica:** autor, año, método, hallazgos y formato de cita.
- **Mercadeo:** audiencia, necesidad, canal, mensaje y resultado observado.

Una ficha puede combinar varias plantillas. Por ejemplo, una Persona puede usar la plantilla Personal y también la Legal si participa en un caso.

## Añadir un campo

Cuando pulses **Más campos**:

1. Busca el dato por su nombre cotidiano.
2. Reutiliza un campo existente si significa lo mismo.
3. Revisa las sugerencias parecidas.
4. Crea uno nuevo únicamente si no existe.
5. Escribe un nombre claro y explica para qué lo necesitas.

Antes de crear “Profesión”, revisa si ya existe “Ocupación”. Esto evita que termines con dos campos para el mismo dato.

## Crear una plantilla propia

Puedes reunir los campos que utilizas con frecuencia y guardar una plantilla como:

- Caso penal;
- Investigación de corrupción;
- Tesis universitaria;
- Análisis de campaña.

Aplicar una plantilla no te obliga a completar datos que todavía desconoces. Tampoco borra información si cambias la plantilla más adelante.

## Cómo se presenta cada dato

| Dato | Cómo lo verás |
| --- | --- |
| Texto o párrafo | Espacio para escribir |
| Fecha o período | Calendario |
| Sí o No | Casilla o interruptor |
| Opciones | Lista de respuestas |
| Etiquetas | Palabras que puedes añadir o quitar |
| Escala | Selector de 1 a 5 |
| Posición entre dos extremos | Barra deslizante |
| Persona, lugar, documento o Fuente | Tarjeta con nombre y vista previa |
| Varias fichas relacionadas | Selector de varios elementos |
| Archivo o imagen | Vista previa |
| Coordenadas | Mapa pequeño |
| Lista de datos | Filas que puedes añadir |
| Resultado calculado | Valor de solo lectura |

La app debe mostrar nombres comprensibles y vistas previas. No necesitas trabajar con códigos internos.
