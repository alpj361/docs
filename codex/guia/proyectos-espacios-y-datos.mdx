Pulse Journal te permite empezar con algo pequeño y añadir organización solo cuando el trabajo la necesita.

> **Nota rápida → Espacio → Proyecto opcional**

Una idea puede quedarse como Nota rápida. Si crece hasta convertirse en una demanda, un artículo, una novela o una investigación, puedes desarrollarla en un Espacio. Si después necesitas coordinar varios trabajos relacionados, puedes reunirlos en un Proyecto.

<Note>
  Esta página explica el modelo que guiará la organización de Pulse Journal. Algunas vistas y formas de trabajo se incorporarán gradualmente a la app.
</Note>

## Qué significa cada nivel

| Nombre | Cuándo usarlo | Ejemplo |
| --- | --- | --- |
| **Nota rápida** | Cuando quieres guardar algo sin interrumpir lo que haces | Una pista, cita, pregunta o idea |
| **Espacio** | Cuando necesitas desarrollar, ordenar y consultar un trabajo | Una demanda, artículo, novela o investigación |
| **Proyecto** | Cuando varios Espacios comparten un propósito, objetivos o contexto | Una serie de demandas o una investigación de largo plazo |
| **Carpeta** | Cuando solo quieres mantener varios elementos juntos | Territorios de un caso o fuentes de un artículo |
| **Codex** | Cuando quieres conservar personas, lugares, organizaciones, fuentes y otros conocimientos reutilizables | La ficha de un diputado que aparece en varios trabajos |

No tienes que crear un Proyecto para utilizar un Espacio. Tampoco necesitas abrir un Espacio para guardar una Nota rápida.

## El Espacio es donde desarrollas el trabajo

Un Espacio no es únicamente una carpeta ni un documento. Es el lugar donde reúnes el contenido principal, las fuentes, las notas, los datos y los elementos de Codex que necesitas para trabajar.

Puede servir para escribir:

- una novela;
- una demanda;
- un artículo;
- una investigación periodística;
- un estudio de mercado;
- una tesis;
- un informe;
- un flujo de trabajo;
- una presentación, cuando este formato esté disponible.

El Espacio conserva el contexto de ese trabajo. Esto ayuda a que tú y tu asistente de IA puedan concentrarse en lo relacionado con el tema, sin recorrer todo lo que has guardado en tu cuenta.

## Divide el contenido según lo que estás haciendo

Cada trabajo puede organizarse de una manera diferente. Una novela no necesita las mismas divisiones que una demanda o una investigación.

| Trabajo | Una organización posible |
| --- | --- |
| **Novela** | Capítulo → Escena → Fragmento |
| **Demanda** | Sección → Apartado → Argumento |
| **Artículo** | Sección → Apartado |
| **Investigación** | Línea de investigación → Hallazgo → Nota |
| **Estudio de mercado** | Área → Análisis → Conclusión |
| **Presentación futura** | Sección → Diapositiva → Elemento |

Los nombres visibles deben adaptarse al trabajo. Lo importante es que puedas dividirlo, reordenarlo y volver a reunirlo sin perder el sentido general.

## Mira el trabajo completo o una parte

Puedes pensar en un documento como un conjunto de piezas relacionadas.

En una novela podrías leer todo el capítulo o concentrarte en una sola escena. En una demanda podrías revisar el escrito completo o trabajar únicamente un argumento. En una investigación podrías abrir una línea completa o un hallazgo específico.

Al consultar a tu IA, también podrás indicar cuánto contexto necesita:

- el fragmento seleccionado;
- la escena o apartado actual;
- el capítulo o sección;
- el documento completo;
- todo el Espacio;
- el Proyecto, cuando necesites relacionar varios Espacios.

Elegir el alcance ayuda a obtener una respuesta más enfocada y evita mezclar trabajos que no corresponden.

## Cómo entra Codex en lo que escribes

Codex conserva las fichas que puedes reutilizar: Personas, Organizaciones, Territorios, Eventos, Fuentes y otros elementos.

Si en una escena escribes “Mark habla”, Pulse Journal puede relacionar ese nombre con la ficha de Mark en tu Codex. Así, tu asistente puede entender a quién te refieres y consultar la información que ya guardaste sobre ese personaje o persona.

Lo mismo puede ocurrir con:

- una empresa mencionada en una demanda;
- un municipio mencionado en una noticia;
- una fuente citada en un artículo;
- un testigo mencionado en una línea de investigación.

Si hay dos personas con el mismo nombre, la app debería pedirte que confirmes cuál es. La referencia queda vinculada al contenido para que no tengas que explicarla de nuevo cada vez.

## Conjuntos de datos: información organizada en filas y columnas

Un **conjunto de datos**, también llamado _dataset_, sirve para guardar y consultar muchos registros de forma ordenada.

Por ejemplo, podrías tener un conjunto con los 160 diputados y columnas como:

- nombre;
- partido;
- distrito;
- asistencia;
- votaciones;
- iniciativas;
- periodo.

No necesitas incluir los 160 diputados dentro de cada Espacio. Puedes conservar el conjunto de datos por separado y relacionarlo solo con los trabajos que lo necesiten.

Un conjunto de datos puede:

- existir por sí mismo;
- relacionarse con uno o varios Espacios;
- acompañar un Proyecto;
- respaldar una sección de un artículo;
- aportar información sobre una Persona de Codex.

## Una misma investigación puede verse de varias formas

Imagina que estás escribiendo un artículo sobre votaciones en el Congreso.

En la vista de **Documento**, narras qué ocurrió y explicas tus conclusiones. En la vista de **Datos**, comparas votaciones, partidos y asistencia. En la vista de **Biblioteca**, consultas las Personas, Fuentes y documentos relacionados.

Según el trabajo, un Espacio podría ofrecer:

- **Documento:** lo que estás escribiendo;
- **Estructura:** capítulos, escenas, secciones o apartados;
- **Biblioteca:** fichas de Codex, fuentes, carpetas y archivos;
- **Datos:** conjuntos de datos, filtros y comparaciones;
- **Mapa:** territorios, áreas y puntos relacionados;
- **Relaciones:** conexiones entre personas, organizaciones, eventos y fuentes.

No todos los Espacios necesitan todas las vistas. Puedes utilizar solo las que ayuden a desarrollar ese trabajo.

## Ejemplo: una serie de demandas

<Steps>
  <Step title="Empieza con una Nota rápida">
    Guardas una contradicción encontrada en una declaración.
  </Step>
  <Step title="Abre un Espacio">
    La nota crece hasta convertirse en una demanda. En el Espacio reúnes el escrito, los hechos corroborados, las pruebas, las Personas y las Fuentes.
  </Step>
  <Step title="Trabaja por secciones">
    Revisas el escrito completo o te concentras en un argumento concreto.
  </Step>
  <Step title="Relaciona los datos">
    Vinculas un conjunto de datos con fechas, expedientes o personas relevantes.
  </Step>
  <Step title="Crea un Proyecto cuando haga falta">
    Si aparecen varias demandas conectadas, las reúnes en un Proyecto para conservar el propósito y contexto compartidos.
  </Step>
</Steps>

## Una regla sencilla para orientarte

> El Proyecto conserva el propósito general. El Espacio conserva el contexto de trabajo. El documento conserva lo escrito. El conjunto de datos conserva los registros. Codex conserva el conocimiento que puedes reutilizar.
