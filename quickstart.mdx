# Inicio rápido con Codex v4.1

Usa como base `https://mcp.standatpd.com`. Las operaciones privadas requieren `Authorization: Bearer <token>`.

## 1. Obtén el schema

```http
GET /api/codex/schema?tipo=Actor
```

La respuesta separa `itemTypes`, `auxiliaryTypes`, `resourceTypes` y `storageTypes`. Usa `field_key` como identidad. El `label` es texto de interfaz y puede cambiar.

## 2. Resuelve antes de crear

```http
POST /api/codex/fields/resolve
```

Reutiliza una coincidencia `matched`. Si hay `candidates`, pide confirmación. Crea un campo personal solo con `not_found`.

## 3. Valida el payload

```http
POST /api/codex/validate-fields
```

Cada valor debe cumplir el shape de su `field_type`. El backend rechaza shapes inválidos e incluye instrucciones de corrección.

## 4. Guarda por claves

```http
PATCH /api/codex/universe-items/:id/fields
```

Envía `fields` y, cuando aplique, `preset_keys`. La respuesta incluye `resolved_fields`. No escribas `details` directamente desde un cliente nuevo.

## 5. Conecta un agente por MCP

Configura el endpoint Streamable HTTP:

```text
https://mcp.standatpd.com/mcp
```

El servidor responde con OAuth cuando falta una sesión. Un `GET /mcp` devuelve `405` por diseño; los mensajes MCP se envían con `POST`.
