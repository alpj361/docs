# Inicio rápido con Codex v4

## 1. Obtén el schema

```http
GET /api/codex/schema?tipo=Actor
```

Usa `field_key` como identidad. El `label` es copy de interfaz y puede cambiar.

## 2. Resuelve antes de crear

```http
POST /api/codex/fields/resolve
```

Reutiliza una coincidencia `matched`. Si hay `candidates`, pide confirmación. Crea un campo personal solo con `not_found`.

## 3. Valida el payload

```http
POST /api/codex/validate-fields
```

Cada valor debe cumplir el shape de su `field_type`. El backend rechaza shapes inválidos e incluye instrucciones de corrección.

## 4. Guarda por claves

```http
PATCH /api/codex/universe-items/:id/fields
```

Envía `fields` y, cuando aplique, `preset_keys`. La respuesta incluye `resolved_fields`.
